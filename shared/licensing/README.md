# چارچوب مشترک مجوز SAHROUD
این پوشه مرجع مشترک تمام نرم‌افزارهای آینده SAHROUD است.

## مدل محصول
- FREE: نسخه رایگان با قابلیت‌های پایه.
- PRO: مجوز تجاری تک‌کاربره/دستگاهی با مدت اعتبار مشخص.
- TEAM: مجوز چندکاربره یا سازمانی.
- TRIAL: آزمایشی با تاریخ پایان.
- EDUCATION: آموزشی، در صورت تعریف محصول.

## امنیت
1. شناسه مجوز یکتا با پیشوند SAHROUD؛ نمونه نمایشی: SAHROUD-TOPO-PRO-2027-XXXXXX.
2. کد فعال‌سازی به‌تنهایی مجوز معتبر نیست؛ سرور باید امضای دیجیتال توکن، محصول، سطح، تاریخ انقضا و وضعیت ابطال را بررسی کند.
3. هیچ کلید خصوصی یا secret در HTML/JavaScript سمت کاربر قرار نگیرد.
4. در حالت آفلاین فقط توکن امضاشده با زمان انقضای محدود قابل پذیرش باشد؛ ساعت دستگاه به‌تنهایی مرجع قابل اعتماد نیست.
5. برای هر محصول شناسه محصول مستقل و برای هر دستگاه شناسه نصب جداگانه تعریف شود.
6. قابلیت‌ها با feature flags از پاسخ معتبر سرور فعال شوند؛ رابط کاربری به‌تنهایی محل اعمال امنیت نیست.
7. بازیابی، انتقال دستگاه، تمدید، ابطال و ثبت رخدادها باید در پنل مدیریت انجام شود.

## وضعیت پیاده‌سازی
این سند قرارداد معماری است، نه سرویس صدور مجوز عملیاتی. پیش از فروش واقعی باید API امن، پایگاه داده، پنل مدیریت، امضای توکن و کنترل ابطال روی سرور راه‌اندازی و آزمون شود.
