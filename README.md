**نسخه رابط کاربری بازطراحی‌شده برای موبایل و لپ‌تاپ**

## تغییرات نسخه 1.3
- رابط فارسی RTL با چیدمان واکنش‌گرا برای موبایل، تبلت و لپ‌تاپ.
- نوار ابزار کناری دسکتاپ و نوار پیمایش پایین موبایل.
- پوسته روشن/تیره با نگهداری انتخاب کاربر.
- کارت‌های خلاصه وضعیت پروژه و شمارنده نقاط.
- دکمه نصب در مرورگرهای پشتیبانی‌کننده؛ در مرورگرهای دیگر از منوی مرورگر گزینه Install / Add to Home Screen استفاده کنید.
- manifest و service worker برای نصب‌پذیری و cache آفلاین پس از استقرار روی HTTPS.
- کنترل‌های لمسی بزرگ‌تر، جدول پیمایش‌پذیر و چیدمان تک‌ستونه در نمایشگر کوچک.
- حفظ موتور تبدیل و قابلیت‌های نسخه 1.2 شامل UTM رفت‌وبرگشت، CSV/TXT/TSV، DXF پایه، LandXML نقاط، QA، Helmert و NMEA GGA.

## امکانات محاسباتی و تبادل داده
- تبدیل WGS84 Latitude/Longitude ↔ UTM و تشخیص/انتخاب Zone و Hemisphere.
- تبدیل DMS، فاصله و آزیموت شبکه‌ای، مساحت و محیط.
- ورود گروهی CSV/TXT/TSV با تشخیص یا تطبیق ستون‌ها؛ خروجی CSV، PNEZD، NEZ و TXT.
- ورود NMEA GGA از جمله GPGGA/GNGGA با کنترل چک‌سام و استخراج کیفیت فیکس، ماهواره، HDOP، UTC، ارتفاع فیلد GGA و جدایی ژئوئید؛ خروجی گزارش CSV.
- ورود DXF متنی ASCII برای POINT و رئوس LWPOLYLINE/VERTEX به‌صورت نقاط؛ خروجی DXF نقاط.
- ورود/خروج پایه LandXML برای CgPoints.
- کنترل کیفیت: شناسه تکراری، نقاط تکراری/نزدیک، زون مورد انتظار و اختلاف رفت‌وبرگشت.
- تبدیل Helmert هفت‌پارامتری با پارامترهای مستند و واردشده توسط کاربر.

## نصب و استفاده آفلاین
برای نصب به‌صورت برنامه مستقل، فایل‌ها باید روی یک مبدأ HTTPS میزبانی شوند و manifest و service worker در همان مسیر در دسترس باشند. پس از بازکردن صفحه در مرورگر سازگار، از دکمه «نصب برنامه» یا گزینه Install / Add to Home Screen استفاده کنید. بازکردن فایل HTML از حافظه گوشی یا لپ‌تاپ همچنان امکان اجرای محاسبات اصلی را می‌دهد، اما نصب PWA و service worker در حالت file:// فعال نیست.

## محدودیت‌های فنی و مهندسی
- DXF: فقط ASCII؛ POINT و رئوس LWPOLYLINE/VERTEX به نقاط مستقل تبدیل می‌شوند. خروجی فعلی POINT است؛ DWG، DXF باینری، بلوک‌ها، خطوط/پلی‌لاین‌های خروجی و سطوح پیچیده پشتیبانی کامل ندارند.
- LandXML: فقط CgPoints پایه؛ TIN، Alignment و ساختارهای پیچیده هنوز پشتیبانی نمی‌شوند.
- پروفایل‌های Leica/Trimble/Topcon/Sokkia الگوهای عمومی ستون‌اند، نه درایور یا رمزگشای فرمت اختصاصی. سازگاری واقعی نیازمند مدل دستگاه/کنترلر و فایل نمونه واقعی است.
- NMEA GGA فقط لاگ موقعیت GGA را می‌خواند؛ اتصال زنده Bluetooth/NTRIP و پردازش RINEX هنوز پیاده‌سازی نشده است. کیفیت Fixed/Float همان پرچم گزارش‌شده در فایل گیرنده است و مستقلاً تأیید نمی‌شود.
- ارتفاع فیلد 9 در GGA طبق استاندارد معمولاً ارتفاع نسبت به MSL است؛ قرارداد سازنده گیرنده باید بررسی شود. ارتفاع بیضوی در صورت وجود جدایی ژئوئید فقط به‌صورت محاسباتی برآورد می‌شود.
- تبدیل UTM بر پایه WGS84 است؛ انتخاب EPSG یا برچسب Datum به‌تنهایی Datum transformation انجام نمی‌دهد.
- Helmert فقط با پارامترهای معتبر، قرارداد چرخش و جهت تبدیل درست قابل استفاده است. پارامتر رسمی ایران حدس زده نشده است.
- Z بدون تبدیل عمودی حفظ می‌شود؛ تبدیل ارتفاع بیضوی به ارتومتریک نیازمند مدل ژئوئید معتبر است.
- محاسبات فاصله و مساحت UTM شبکه‌ای‌اند؛ پروژه‌های بزرگ، مرز زون‌ها و کار حساس نیازمند کنترل ژئودتیکی مستقل هستند.
- نبود هشدار QA صحت Datum، CRS، برداشت میدانی یا ارتفاع را اثبات نمی‌کند.

## آزمون‌ها و وضعیت اعتبارسنجی
- کد JavaScript از نظر نحوی بررسی شده است.
- آزمون‌های عددی داخلی UTM و آزمون parser نمونه NMEA GGA قبلاً اجرا شده‌اند.
- رابط واکنش‌گرا، پوسته تاریک/روشن، نصب PWA و service worker به آزمون میدانی روی دستگاه‌های واقعی نیاز دارند.
- این نسخه آزمایشی است و پیش از استفاده اجرایی حساس باید با نقاط کنترل رسمی و فایل واقعی دستگاه کنترل شود.
