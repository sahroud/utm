# Sahroud UTM Pro — نسخه آزمایشی 1.1

فایل اجرایی مستقل: [Sahroud-UTM-Pro-v1.1.html](./Sahroud-UTM-Pro-v1.1.html)

## امکانات
- تبدیل دوطرفه WGS84 جغرافیایی و UTM، تشخیص/انتخاب زون و نیم‌کره
- ورود گروهی CSV/TXT/TSV و تطبیق ستون‌ها؛ خروجی CSV استاندارد، PNEZD عمومی، NEZ، ENZ و TXT تب‌دار
- محاسبه فاصله و آزیموت شبکه‌ای، مساحت و محیط
- ورود/خروجی DXF متنی ASCII برای Entityهای نقطه (POINT)
- ورود/خروجی LandXML پایه برای CgPoints (ترتیب N,E,Z)
- کنترل کیفیت اولیه: شناسه تکراری، مختصات نزدیک/تکراری، زون مورد انتظار و اختلاف رفت‌وبرگشت
- تبدیل ژئودتریک WGS84 به Datum مقصد با Helmert هفت‌پارامتری قابل ورود توسط کاربر (Position Vector)

## محدودیت‌های مهم
- DXF: فقط ASCII و نقاط POINT؛ DWG، DXF باینری، بلوک‌ها، خطوط و سطوح پیچیده پشتیبانی کامل ندارند.
- LandXML: فقط CgPoints پایه؛ سطح TIN، Alignment و ساختارهای پیچیده LandXML هنوز پشتیبانی نمی‌شوند.
- پروفایل‌های Leica/Trimble/Topcon/Sokkia در این نسخه راهنمای تطبیق فایل متنی عمومی‌اند، نه درایور یا رمزگشای فرمت اختصاصی سازندگان. برای پروفایل دقیق، نمونه واقعی خروجی و مدل دستگاه لازم است.
- تبدیل Helmert فقط زمانی معتبر است که پارامترها، قرارداد چرخش، جهت تبدیل، بیضوی مقصد و محدوده کاربرد از مرجع معتبر مشخص شده باشند. هیچ پارامتر رسمی برای ایران حدس زده نشده است.
- تبدیل Helmert فعلی خروجی جغرافیایی Datum مقصد می‌دهد؛ تبدیل Projection مقصد باید جداگانه با تعریف CRS کامل انجام شود.
- ارتفاع ورودی حفظ می‌شود؛ تبدیل ارتفاع بیضوی به ارتومتریک/سطح دریا با ژئوئید انجام نمی‌شود.
- نبود هشدار کنترل کیفیت، صحت Datum، برداشت میدانی یا ارتفاع را تضمین نمی‌کند.
